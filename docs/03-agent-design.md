# AI Agent Design

The AI Job Agent system uses an agent-based architecture.

Agents operate as specialized components.

---

# Agents

Job Discovery Agent

Responsible for:

- collecting job postings
- scheduling scrapers
- aggregating results

---

Job Matching Agent

Responsible for:

- embedding comparison
- job ranking
- filtering results

---

Cover Letter Agent

Responsible for:

- generating personalized cover letters
- using job description context

---

Orchestrator Agent

Responsible for coordinating the workflow:

1. fetch jobs
2. compute embeddings
3. run matching
4. generate cover letters
